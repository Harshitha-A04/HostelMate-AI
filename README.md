🏠 HostelMate AI

Smarter Hostels, Happier Students

📌 About the Project

HostelMate AI is a smart, web-based hostel management platform designed to make hostel life easier and more organised for students and wardens.

It provides a single platform to access hostel services, manage complaints, check mess menus, submit leave requests and receive hostel updates.

🎯 Objectives

- Simplify hostel management activities.
- Reduce manual paperwork.
- Improve communication between students and wardens.
- Make hostel services easily accessible.
- Provide a user-friendly digital platform.

✨ Features

- 👨‍🎓 Student Dashboard
- 👨‍💼 Warden Dashboard
- 🛠️ Complaint Management
- 🍛 Daily Mess Menu
- 🧳 Leave Request Management
- 📢 Hostel Notifications
- 🤖 AI Chat Interface
- 🌓 Light and Dark Mode
- 📱 Responsive User Interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run the project using the Live Server extension.
5. Explore the HostelMate AI website.

💡 Benefits

- Saves time for students.
- Makes complaint submission easier.
- Improves hostel communication.
- Reduces manual work.
- Organises hostel activities in one place.
